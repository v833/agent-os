# 可观测性大盘

Agent OS 内置可观测性能力，记录任务吞吐、Token 消耗、时延分布与链路追踪记录，可通过 `/metrics` 命令按当前 Bot 与当前会话范围查询。

---

## 查看指标大盘

```text
@机器人 /metrics
```

返回当前 Bot、当前群聊或私聊范围内的指标大盘，包括：

- 任务总数与成功 / 失败 / 暂停 / 取消 / 运行中分布；
- 成功率；
- 总耗时、平均耗时与 P50 / P90 / P99 时延分位数；
- Token 消耗（总 / 输入 / 输出 / 缓存读 / 缓存创建）；
- 按 Bot、按引擎、按工具的细分布。

---

## 查看链路追踪记录

```text
@机器人 /metrics traces
```

返回最近的 10 条 Trace 记录，每条展示状态图标（✅ 成功 / ❌ 失败 / ⏸️ 暂停 / ⏹️ 取消 / ⏳ 进行中）、链路 ID、所属 Bot 与引擎、耗时与 Token。

---

## 查看单个 Bot 指标

```text
@机器人 /metrics bot <Bot ID>
```

返回指定 Bot 的任务总数、成功率、Token 消耗与平均耗时。

> 出于数据隔离，`/metrics bot` 只能查询当前 Bot 自身的指标；查询其他 Bot 会被拒绝。

---

## 指标语义

- **吞吐**：任务总数及成功 / 失败等状态分布，反映单位时间处理能力。
- **Token 消耗**：输入、输出、缓存读写 Token，反映模型资源使用。
- **时延分位数**：P50 / P90 / P99，反映任务耗时分布的稳定性与尾延迟。
- **链路记录**：Trace 记录任务从开始到终态的全过程，含工具调用次数与失败次数。

> 提示：可观测性能力由 `observability` 插件提供，可在 `cordis.yml` 中移除以整体下线；命令 `/metrics` 与链路记录均按当前租户边界查询。
