# 斜杠命令全解析

在飞书话题中，除了直接输入自然语言，你还可以通过斜杠命令（`/command`）精准控制会话、切换目录、调度引擎与触发自动化任务。

在飞书群中发送 `@机器人 /help`，可随时查看当前在线的所有命令。

---

## 一、本地全局命令行工具 (`tpl`)

当你全局安装了 `threadpilot` 后，开发机终端提供 `tpl`（及别名 `threadpilot`）命令：

```bash
# 启动常驻服务（自动读取当前目录的 .env 与 config/bots.json）
tpl

# 打印当前版本号
tpl -v
# 或: tpl --version

# 查看命令行帮助
tpl -h
# 或: tpl --help

# 检查 npm registry 是否有新版本并提示升级
tpl update
```

## 二、飞书会话与工作目录控制

### `/new` - 清空历史，开启新会话
- **格式**：`@机器人 /new [任务描述]`
- **说明**：立即清除当前话题对应的底层 CLI 上下文，重新初始化一个干净的空会话。当你需要在这个话题中转向一个完全不相关的新任务时使用。
- **示例**：`@开发工程师 /new 重构用户认证模块`

### `/resume` - 恢复历史会话
- **格式**：`@机器人 /resume <sessionId>`
- **说明**：通过 CLI 会话 ID 重新挂载指定的历史会话，继续之前的上下文工作。

### `/compact` - 压缩整理上下文
- **格式**：`@机器人 /compact [保留重点说明]`
- **说明**：驱动底层 CLI（如 Claude Code 或 Codex）的原生整理协议，浓缩提炼长对话要点，释放 Token 窗口。部分无原生 compact 协议的引擎（如 agy）会给出明确提示。
- **示例**：`@开发工程师 /compact 保留架构决策和未修复的缺陷列表`

### `/cd` - 查看与切换项目工作目录
- **格式**：
  - 查询当前目录：`@机器人 /cd`
  - 切换工作目录：`@机器人 /cd <绝对路径或相对路径>`
- **说明**：安全切换任务运行的工程路径，并在新目录中以新上下文就绪。
- **示例**：`@开发工程师 /cd D:\projects\ecommerce-backend`

### `/close` - 结束并归档话题
- **格式**：`@机器人 /close`
- **说明**：显式关闭并归档当前话题的活跃会话，释放后台常驻子进程资源。

## 三、团队状态与可观测性

### `/team` - 查看团队成员状态
- **格式**：`@任意机器人 /team`
- **说明**：返回当前团队卡片，展示各成员的长连接在线状态、默认 CLI 引擎、绑定的工作区目录及专业技能列表。

### `/status` - 查看当前话题状态
- **格式**：`@机器人 /status`
- **说明**：返回当前话题的会话运行状态、绑定的会话 ID、当前使用的 CLI 引擎以及累计耗时与资源用量。

### `/metrics` - 可观测性指标大盘
- **格式**：
  - `@机器人 /metrics`：查看当前群聊范围内该 Bot 的吞吐量、Token 消耗总量、平均耗时与时延分位数（p50/p90/p99）。
  - `@机器人 /metrics traces`：查看最近 10 条真实任务的链路 Trace 记录。
  - `@机器人 /metrics bot <botId>`：过滤查看特定成员的详细指标。

## 四、自动化与高级功能

### `/schedule` 与 `/schedules` - 定时任务
- **创建任务**：`@机器人 /schedule <自然语言需求>`（例如：`@机器人 /schedule 每天早上 9 点检查日志并汇报`）
- **查看任务**：`@机器人 /schedules`（列出当前聊天中由自己创建的所有计划）
- **管理任务**：
  - 暂停：`@机器人 /schedule pause <id>`
  - 恢复：`@机器人 /schedule resume <id>`
  - 删除：`@机器人 /schedule delete <id>`
  - 立即执行一次：`@机器人 /schedule run <id>`

### `/board` - 飞书多维表格看板
- **一键建表**：`@机器人 /board init [看板名称]`
- **查看看板链接**：`@机器人 /board link`
- **查看同步状态**：`@机器人 /board status`
- **强制重建**：`@机器人 /board init --force`

### `/orchestrate` 与 `/panel` - 多话题并行编排
- **发起大任务拆解**：`@机器人 /orchestrate <复杂任务>`
- **查看编排面板**：`@机器人 /panel`（汇总子任务卡片进度，支持对失败子任务一键点击重试）

### `/login` - CLI 认证登录
- **格式**：
  - 为当前引擎发起登录：`@机器人 /login`
  - 为指定引擎发起登录：`@机器人 /agy login`
- **说明**：当引擎未登录或 Token 失效时，弹出飞书卡片引导完成 OAuth 授权码或设备码验证。

## 五、显式指定引擎执行单次任务

即使 Bot 配置了默认引擎，你依然可以在消息前加前缀显式指定特定引擎：

| 命令前缀 | 调用的底层 CLI | 示例 |
| :--- | :--- | :--- |
| `/codex` | OpenAI Codex CLI | `@机器人 /codex 检查数据库迁移脚本` |
| `/claude` | Anthropic Claude Code CLI | `@机器人 /claude 分析组件重渲染原因` |
| `/dimagent` | DimAgent CLI | `@机器人 /dimagent 编写通用跨平台脚本` |
| `/agy` | Google Antigravity CLI | `@机器人 /agy 修复 TypeScript 类型推导错误` |
