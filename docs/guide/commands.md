# 斜杠命令全解析

在飞书话题中，除了直接输入自然语言，你还可以通过简洁的斜杠命令（`/command`）快速控制会话与查询状态。

---

## 团队与状态查询

### `/team` - 团队状态全览
- **用法**：`@任意机器人 /team`
- **效果**：立即返回团队成员卡片，展示各成员当前是否在线（长连接状态）、默认执行引擎、工作目录及绑定的专业技能。

### `/status` - 当前话题状态
- **用法**：`@机器人 /status`
- **效果**：查看当前话题的会话运行状态、绑定的会话 ID、当前使用的 CLI 引擎以及累计耗时与资源用量。

---

## 会话与目录控制

### `/new` - 开启崭新会话
- **用法**：`@机器人 /new [可选的新任务描述]`
- **效果**：立即清除当前话题中的 CLI 历史上下文记忆，开启一个全新的干净会话。当你需要彻底切换话题方向时非常实用。

### `/resume` - 恢复历史会话
- **用法**：`@机器人 /resume <sessionId>`
- **效果**：通过会话 ID 重新挂载指定的历史会话，继续之前的上下文工作。

### `/compact` - 上下文紧凑整理
- **用法**：`@机器人 /compact`
- **效果**：通知底层 CLI（如 Claude Code / Codex）触发上下文整理协议，提炼历史对话要点，释放 Token 上下文窗口。

### `/cd` - 工作目录查询与切换
- **用法**：
  - 查询当前工作目录：`@机器人 /cd`
  - 切换到新目录：`@机器人 /cd C:\path\to\your\project`
- **效果**：安全切换任务运行的工程路径，并在新目录中以崭新上下文就绪。

### `/close` - 结束并归档话题
- **用法**：`@机器人 /close`
- **效果**：显式关闭并归档当前话题的活跃会话，释放后台驻留资源。

---

## 引擎显式调度

如果你想在单次任务中临时指定某种特定的 CLI 引擎执行，可以在命令前加上引擎名称：

- `@机器人 /codex 检查数据库连接池实现`
- `@机器人 /claude 分析当前前端组件的渲染性能`
- `@机器人 /dimagent 编写一个跨平台脚本`
