# 斜杠命令全解析

在飞书话题中，除了直接输入自然语言，你还可以通过简洁的斜杠命令（`/command`）快速控制会话、查询状态、调度引擎与编排任务。本章是命令全集，与 `/help` 输出保持一致。

> 提示：任何时候发送 `@机器人 /help`，即可在飞书内查看最新命令清单。

---

## 团队与状态查询

### `/team` - 团队状态全览
- **用法**：`@任意机器人 /team`
- **效果**：立即返回团队成员卡片，展示各成员当前是否在线（长连接状态）、默认执行引擎、工作目录及绑定的专业技能。

### `/status` - 当前话题状态
- **用法**：`@机器人 /status`
- **效果**：查看当前话题的会话运行状态、绑定的会话 ID、当前使用的 CLI 引擎以及累计耗时与资源用量。

### `/metrics` - 可观测性指标大盘
- **用法**：
  - `@机器人 /metrics`：查看当前 Bot 在当前会话范围内的吞吐、Token 消耗与时延分布大盘。
  - `@机器人 /metrics traces`：查看最近 10 条链路追踪记录。
  - `@机器人 /metrics bot <Bot ID>`：查看当前 Bot 的任务成功率、Token 与平均耗时。
- **效果**：按「当前 Bot + 当前群聊/会话」范围隔离展示，避免跨群或跨 Bot 泄露任务元数据。

## 会话与目录控制

### `/new` - 开启崭新会话
- **用法**：`@机器人 /new [可选的新任务描述]`
- **效果**：立即清除当前话题中的 CLI 历史上下文记忆，开启一个全新的干净会话。当你需要彻底切换话题方向时非常实用。

### `/resume` - 恢复历史会话
- **用法**：`@机器人 /resume <sessionId>`
- **效果**：通过会话 ID 重新挂载指定的历史会话，继续之前的上下文工作。

### `/compact` - 上下文紧凑整理
- **用法**：`@机器人 /compact [可选要求]`
- **效果**：通知底层 CLI（如 Claude Code / Codex）触发上下文整理协议，提炼历史对话要点，释放 Token 上下文窗口。部分引擎（如 Antigravity）暂不支持原生 compact，会明确提示改在话题中发起整理任务。

### `/cd` - 工作目录查询与切换
- **用法**：
  - 查询当前工作目录：`@机器人 /cd`
  - 切换到新目录：`@机器人 /cd C:\path\to\your\project`
- **效果**：安全切换任务运行的工程路径，并在新目录中以崭新上下文就绪。

### `/close` - 结束并归档话题
- **用法**：`@机器人 /close`
- **效果**：显式关闭并归档当前话题的活跃会话，释放后台驻留资源。

## 定时任务、看板与编排

### `/schedule` - 定时任务
- **用法**：
  - 创建：`@机器人 /schedule <自然语言需求>`，例如 `/schedule 每天早上 9 点检查服务日志`
  - 查看：`@机器人 /schedules`（当前聊天中由自己创建的计划）
  - 管理：`@机器人 /schedule pause|resume|delete|run <任务id>`
- **效果**：到点直接唤醒目标成员的 CLI 会话静默执行任务，不向群里推派发消息（详见「定时任务」章节）。

### `/board` - 飞书多维表格任务看板
- **用法**：
  - 一键初始化：`@机器人 /board init [看板名称]`
  - 覆盖重建：`@机器人 /board init --force [看板名称]`
  - 查看链接：`@机器人 /board link`
  - 查看状态：`@机器人 /board status`
  - 查看帮助：`@机器人 /board help`
- **效果**：一键创建多维表格并挂载双向同步服务，实现任务生命周期实时写表与表格反向拉起新任务（详见「任务看板」章节）。

### `/orchestrate` - 大任务并行编排
- **用法**：`@机器人 /orchestrate <大任务>`
- **效果**：把一个大任务拆解为多个子任务，并行派发给团队成员执行（详见「并行编排」章节）。

### `/panel` - 编排进度面板
- **用法**：`@机器人 /panel`
- **效果**：展示当前群聊与 Bot 的编排运行进度汇总卡片，可查看子任务状态并对失败子任务一键重试。

## 登录

### `/login` - 为当前引擎发起登录
- **用法**：
  - `@机器人 /login`：为当前会话绑定的引擎发起登录卡片流程。
  - `@机器人 /agy login`：为 Antigravity 引擎发起登录。
- **效果**：当引擎未认证时弹出登录卡片，引导完成 OAuth 或设备码授权（详见「CLI 登录」章节）。任务因认证失败时，系统也会自动补发登录卡片。

## 引擎显式调度

如果你想在单次任务中临时指定某种特定的 CLI 引擎执行，可以在命令前加上引擎名称，ThreadPilot 会在该引擎上开启新话题执行：

- `@机器人 /codex 检查数据库连接池实现`
- `@机器人 /claude 分析当前前端组件的渲染性能`
- `@机器人 /dimagent 编写一个跨平台脚本`
- `@机器人 /agy 修复这条报错`

### 引擎矩阵

ThreadPilot 通过「一切皆为插件」架构支持多引擎，已在 `cordis.yml` 装配的引擎如下：

| 引擎 | 调度前缀 | 说明 |
| :--- | :--- | :--- |
| Codex | `/codex` | OpenAI Codex，主路径 headless 接入 |
| Claude Code | `/claude` | Anthropic Claude Code headless 接入 |
| DimAgent | `/dimagent` | headless 接入；另提供标准 ACP 接入 |
| Antigravity | `/agy` | Google Antigravity CLI（agy）headless 接入 |

**标准 ACP 接入**：除了上述 headless 适配器，ThreadPilot 还支持通过标准 Agent Client Protocol（ACP）接入任何提供 ACP server 的 CLI。当前装配中，DimAgent（`dim acp`）与 Claude（官方 ACP 适配器）均通过标准 ACP 通道注册。ACP 接入与具体供应商解耦——在 `cordis.yml` 的 `engines/acp` 插件 `engines` 列表中声明 `id/command/args`，即可接入任意 CLI，无需改动核心代码。
