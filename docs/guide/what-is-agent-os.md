# 产品简介与价值

## 什么是 Agent OS？

**Agent OS** 是一款专为研发团队打造的**新一代企业级多智能体协同平台**。

以往，使用 Claude Code、OpenAI Codex、DimAgent 或 Google Antigravity (agy) 等强大编程 CLI 时，工程师必须坐在电脑前，在黑底白字的终端窗口中敲击命令并逐一审查。这种模式面临三大痛点：

1. **操作门槛高**：产品经理、测试人员或管理者无法直接触达这些强大的命令行工具。
2. **协作割裂**：任务无法在即时通讯软件中透明流转，进度别人看不到，交接靠人工复制粘贴。
3. **单兵作战**：各个工具彼此孤立，缺乏角色化分工（需求澄清、代码编写、用例测试各干各的）。

**Agent OS 把飞书彻底变成了 AI 编程 CLI 的智能指挥台**。团队成员只要在飞书群聊里像跟真人同事沟通一样发送一条消息，Agent OS 就会自动唤醒底层各专职 Bot，完成从需求拆解、方案确认、代码编写到质量验证的全流程。

## 核心产品价值（站在用户视角）

### 1. 极简的飞书原生体验
- **话题即任务**：在飞书话题群中 @机器人 发起需求，同一话题自动续接上下文，像开会一样自然讨论任务。
- **免公网 IP 部署**：基于飞书长连接（WebSocket）技术，企业内网机器或个人开发机无需公网 IP 和复杂反向代理，开箱即用。

### 2. 透明可视的实时动态
- **执行过程尽收眼底**：Agent 正在查看哪个文件、修改哪行代码、执行哪条终端命令，都会在一秒内实时更新到飞书互动卡片中。
- **掌控由你，随时终止**：如果发现 Agent 方向偏离，发起人只需点击卡片底部的「停止任务」，即可安全阻断执行。

### 3. 多角色智能体团队自主协作
Agent OS 内置了专业的“数字研发团队”：
- **CEO 助理（Team Leader）**：理解战略目标、拆解并组织分工、汇总阶段性成果。
- **产品经理（Product Manager）**：主动通过结构化问卷澄清需求，输出云文档产品说明书与交付切片（Spec & Tickets）。
- **开发工程师（Developer）**：负责在工作区精准执行代码编写与功能实现。
- **测试工程师（QA Engineer）**：自动在独立的隔离快照中执行构建与自动化测试，严格把控质量门禁。

## 适用人群与场景

- **研发管理者 / CEO**：在飞书群中直接发起业务目标，指挥数字团队快速产出原型与文档。
- **产品经理**：让 AI 编程工具直接理解自己的产品意图，并通过互动表单对细节进行对齐。
- **一线工程师**：出门在外用飞书手机端就能让开发机上的 Agent 完成 Bug 修复和回归测试。
- **测试人员**：让 QA Bot 自动在隔离环境做全量测试并生成标准缺陷清单。
