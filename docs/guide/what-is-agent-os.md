# 产品简介

## ThreadPilot 是什么

ThreadPilot 将 Claude Code、OpenAI Codex、DimAgent 和 Google Antigravity (agy) 等命令行编程工具接入飞书。团队成员直接在飞书话题群中与对应角色的 Bot 沟通，由 Bot 在后台调用本地 CLI 完成代码读取、编写和验证。

系统通过飞书 WebSocket 长连接与开放平台通信，部署在内网或个人开发机上，不需要公网 IP。

---

## 核心特性

### 话题即任务
- 在飞书群内新建话题并 `@机器人` 发送任务描述。
- 同一话题内的后续回复会自动附带历史上下文，不需要重复交代背景。
- 不同话题对应独立的会话状态，互不影响。

### 实时执行卡片
- 任务执行期间，飞书互动卡片实时更新当前调用的工具（如查看文件、执行终端命令）、运行时长与 Token 消耗。
- 任务发起人可点击卡片底部的「停止」按钮中断当前执行。

### 角色分工
团队预置四个明确分工的 Bot：
- **CEO 助理（Team Leader）**：理解目标，拆解分工并派发任务给团队成员，最后汇总成果。
- **产品经理（Product Manager）**：通过问卷卡片澄清歧义，输出云文档形式的产品说明与任务切片。
- **开发工程师（Developer）**：在工作区中编写代码并安装依赖。
- **测试工程师（QA Engineer）**：在独立的快照环境中运行构建与自动化测试，输出判定与缺陷列表。

---

## 适用场景

- **移动端与远程发起**：通过飞书移动端或桌面端提交修复任务，无需远程登录终端。
- **多人查看与协同**：执行日志与阶段产物发布在公共话题中，团队成员可直接查看进展。
- **需求对齐**：产品经理通过卡片选项直接确认技术方案或功能细节。
- **快照测试**：由 QA Bot 在隔离目录中复现测试用例，避免直接修改开发目录未提交的代码。
