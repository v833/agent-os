# 常见问题与排查指南

整理用户在飞书使用 Agent OS 过程中最常见的问题与解决方案。

---

## 1. 为什么 @机器人 没有回复？

- **检查机器人是否已加入话题群**：在飞书群设置中，确认对应的智能体应用已被添加到群机器人列表中。
- **检查服务进程状态**：确认控制台或服务器上 `pnpm start` 处于运行状态，并出现 `ws client ready` 日志。
- **检查凭证配置**：确认 `.env` 文件中的 App ID 和 App Secret 与飞书开放平台一致，且没有多余空格。

---

## 2. 任务卡片提示“执行超时”怎么办？

- 默认超时时间为防止任务长时间挂起而设置。
- 如果代码库非常庞大或任务较繁重，可以通过更细粒度的指令来缩小范围，例如指明具体文件路径，或分步执行。
- 发起人也可以点击卡片上的「重试」重新拉起任务。

---

## 3. 发送图片为什么没有被识别？

- 请注意：**不要只发送单张裸图片**。
- 请在飞书富文本输入框中，将**文本描述**与**图片**放入同一条消息一并发送（例如：`@开发工程师 这张图里的布局样式如何调整？` 并附带截图）。
- Agent OS 依赖同一消息事件内的资源 ID 解析并自动下载媒体。

---

## 4. 如何防止代码被错误修改？

- **方案前置确认**：先通过 `@产品经理` 或 `@CEO助理` 出具方案，并在飞书卡片上点击确认后再由开发工程师动工。
- **随时紧急刹车**：观察卡片中实时汇报的工具轨迹，一旦发现偏离预期，立即点击卡片右下角的「停止」按钮。
- **QA 隔离保护**：QA 阶段均在独立快照环境运行，不会污染生产或主分支工作树。
