# 常见问题

飞书使用过程中的常见问题与排查方法。

---

## 1. 为什么 @机器人 没有回复？

- **检查机器人是否在群内**：在飞书群设置中，确认对应 Bot 已被添加到群聊。
- **检查服务运行状态**：确认后台 `pnpm start` 处于运行状态，并输出了 `ws client ready` 日志。
- **检查凭证配置**：确认 `.env` 文件中的 App ID 和 App Secret 与飞书开放平台配置一致。

---

## 2. 任务卡片提示“执行超时”怎么办？

- 引擎未显式配置 `<ENGINE>_TIMEOUT_MS` 或 `CLI_TIMEOUT_MS` 时默认不限制单轮执行时长。
- 若设置了超时时间且被触发，可拆细任务范围后重新在话题中发消息，或由发起人点击卡片上的「重试」。

---

## 3. 发送图片为什么没有被识别？

- 请将**文本描述**与**图片**放在同一条消息中发送（例如：`@开发工程师 请看图中报错原因` 并附截图）。
- 若只发送一张纯图片而不带文本描述，系统无法关联需要处理的具体指令。

---

## 4. 如何防止代码被意外覆盖？

- **方案确认闭环**：通过 `@产品经理` 出具方案，并在飞书卡片上点击确认后再由开发工程师实现。
- **运行中停止**：观察卡片中展示的工具调用，若需要调整可点击卡片上的「停止」按钮中断执行。
- **QA 隔离保护**：QA 验证在独立快照目录中运行，不修改当前工作区未提交的文件。
