# Agent OS 完整使用说明书

欢迎使用 Agent OS。本文档专为飞书用户编写，全面介绍如何在飞书群聊中与数字 Agent 团队互动、执行开发任务并掌控全流程。

---

## 1. 任务发起与会话交互

### 1.1 话题即任务（线程隔离）
- **新建任务**：在飞书群中点击“新建话题”，`@指定成员` 并输入任务要求。
- **上下文延续**：在同一话题内继续回复消息时，无需再次反复交代项目背景，底层 Agent 会自动关联本话题的历史对话记录。
- **任务隔离**：不同的飞书话题对应独立的任务会话，彼此之间的运行状态与上下文严格隔离，互不干扰。

### 1.2 支持富文本与多媒体
- **代码块与排版**：可以直接在飞书消息中粘贴代码、Markdown 列表或引用，Agent 会完整解析其中的语法。
- **图片与文件识别**：
  - 发送方式：在同一条消息中上传图片或文件，并附上文字说明（例如：`@开发工程师 帮我看一下报错截图中这行提示是什么原因`）。
  - Agent OS 会自动将资源下载并送入多模态模型中进行解析。

---

## 2. 实时交互卡片与任务生命周期

在任务执行期间，飞书界面会展示一张动态自刷新的卡片：

### 2.1 状态与颜色流转
- **🔵 蓝色（执行中）**：
  - 实时展示当前正在调用的工具（如：查看文件、搜索代码、执行终端命令、创建文件）。
  - 展示当前任务累计执行秒数以及消耗的 Token 数量。
- **🟢 绿色（已完成）**：
  - 任务成功收敛，正文展示清晰的排版结论。如果答案较长，剩余内容会自动续接在话题下方。
- **🔴 红色（执行失败）**：
  - 发生异常或超时时展示，错误信息折叠显示，便于排查问题。
- **⚪ 灰色（已中止）**：
  - 发起人主动点击「停止」按钮后，任务被安全中断，不残留僵尸进程。

### 2.2 一键停止控制
为了防止 Agent 陷入死循环或大范围误改代码，卡片右下角常驻「停止」按钮。只有当前任务的发起人拥有停止权限，保障多人协同群的安全。

## 3. 需求澄清机制（拒绝盲目猜测）

当你的需求存在未确定的技术选型、业务分支或边界条件时，Agent 会主动发起结构化澄清，而不是凭空假设。

1. **澄清卡片弹出**：群内会收到一张专属的问卷选择卡片。
2. **多选题/单选题勾选**：用户直接在飞书卡片中点击选项，或在输入框中填写补充说明。
3. **提交恢复执行**：点击提交后，Agent 会基于你的明确意图立刻恢复代码编写，确保交付物 100% 符合预期。

## 4. 团队智能体自主协同

通过向 **CEO 助理** 或团队成员发起复合目标，数字团队将自动进行职责流转：

### 4.1 典型流转链路
1. **目标下达**：用户在群里 `@CEO助理` 提出高层任务（如：“为当前系统开发一套导出 Excel 功能”）。
2. **需求澄清与 Spec 出具**：CEO 助理将任务拆解后，派发给 **产品经理**。产品经理梳理边界并产出产品说明书。
3. **真人确认方案**：卡片展示产品方案预览，用户点击「确认方案」后，流程进入研发环节。
4. **开发实现**：**开发工程师** 接手任务，进行代码编码、依赖安装与单元测试。
5. **QA 验收门禁**：完成后交由 **QA 工程师** 在干净的隔离环境中自动执行验证。验证通过后，CEO 助理向用户汇报最终成果。

## 5. 工作区与项目目录管理

每个话题默认使用 Bot 绑定的主工作目录。如果需要临时切换到机器上的其他工程项目，可在话题中使用 `/cd` 命令：

- **查看当前目录**：
  ```text
  @开发工程师 /cd
  ```
- **切换目录**：
  ```text
  @开发工程师 /cd D:\projects\my-web-app
  ```
切换目录后，Agent 将自动重置当前话题的 CLI 上下文，以新目录作为后续所有文件读取与命令执行的基础。

## 6. 安全与权限边界

Agent OS 在多人协同群中内置了明确的权限边界，避免越权操作：

- **任务停止鉴权**：只有当前任务的发起人可以点击「停止」按钮安全终止任务，其他成员无法中断。
- **派发鉴权**：只有 Team Leader（CEO 助理）可以在运行时派发任务给团队成员；其他成员调用 `dispatch_task` 会被拒绝，且目标必须来自团队名单、不能派给自己。
- **方案确认鉴权**：产品方案确认卡只有任务发起人可以确认；登录 key 也只有发起人可以提交。
- **编排重试鉴权**：失败子任务一键重试仅允许编排发起人触发，并内置去重与次数上限。
- **QA 隔离保护**：QA 阶段在独立快照环境运行，不污染开发工作树或主分支，并校验审查版本与快照版本一致。
- **数据隔离**：`/metrics`、`/panel` 等查询均按「当前 Bot + 当前群聊 / 会话」范围过滤，避免跨群或跨 Bot 泄露任务元数据。

## 7. 更多能力

- **定时任务**：用 `/schedule` 创建周期任务，到点自动开工（见「定时任务」章节）。
- **任务看板**：用 `/board` 一键初始化飞书多维表格看板，双向同步任务（见「任务看板」章节）。
- **并行编排**：用 `/orchestrate` 拆解大任务并行派发，`/panel` 查看进度（见「并行编排」章节）。
- **可观测性**：用 `/metrics` 查看吞吐、Token、时延与链路记录（见「可观测性大盘」章节）。
- **CLI 登录**：用 `/login` 或 `/<引擎> login` 完成引擎认证（见「CLI 登录」章节）。

完整命令清单与引擎矩阵请参阅「斜杠命令全解析」。
