# 使用手册

本文档说明如何在飞书话题群中与各角色 Bot 交互、查看执行状态、参与方案确认与配置工作目录。

---

## 1. 发起任务与会话交互

### 1.1 话题与会话对应关系
- **发起任务**：在飞书群中新建话题，`@对应角色` 并输入需求。
- **上下文延续**：在同一话题内继续回复消息时，Bot 会携带该话题的历史对话记录继续处理。
- **任务隔离**：不同话题对应独立的会话状态与工作目录设置，互不干扰。

### 1.2 消息格式与附件
- **文本与代码**：支持在消息中直接粘贴文本、Markdown 格式或代码块。
- **图片与文件**：在同一条消息中上传图片或文件并附带文字描述。系统会自动下载并在多模态模型中解析。

---

## 2. 交互卡片与任务状态

任务运行期间，飞书话题内会展示一张实时更新的状态卡片：

### 2.1 状态说明
- **执行中（蓝色）**：显示当前调用的工具名（如查看文件、执行终端命令）、运行耗时与 Token 消耗。
- **已完成（绿色）**：执行结束，正文显示结论。超出卡片长度的详细内容会作为话题回复附在下方。
- **执行失败（红色）**：发生错误或超时，展开可查看具体错误日志。
- **已中止（灰色）**：发起人点击「停止」按钮后，任务进程被安全终止。

### 2.2 停止运行
卡片右下角提供「停止」按钮。只有当前任务的发起人点击有效，防止他人误中断任务。

---

## 3. 需求澄清流程

当需求存在未确定的技术选型或业务边界时，产品经理或对应 Bot 会调用澄清工具弹出问卷卡片：

1. 群内展示单选或多选表单。
2. 用户直接在卡片上勾选选项，或在输入框中填写补充说明并提交。
3. 提交后 Bot 读取选项并继续执行，不再向用户追问已确认的项。

---

## 4. 角色协作流程

向 **CEO 助理** 提交复合任务时，团队按以下步骤流转：

1. **目标输入**：用户在话题中 `@CEO助理` 提出目标。
2. **需求拆解与文档**：CEO 助理将任务派发给 **产品经理**，产品经理梳理边界并输出产品方案与 Tickets。
3. **方案确认**：卡片展示方案摘要，用户点击「确认方案」后进入开发阶段。
4. **代码实现**：**开发工程师** 接收方案，在工作区编写代码并执行基础验证。
5. **QA 验收门禁**：完成后交由 **QA 工程师** 在隔离快照目录中执行验证。验证通过后，CEO 助理向用户汇报最终成果。

---

## 5. 工作区与项目目录管理

每个话题默认使用 Bot 绑定的主工作目录。如果需要临时切换到机器上的其他工程项目，可在话题中使用 `/cd` 命令：

- **查看当前目录**：
  ```text
  @开发工程师 /cd
  ```
- **切换目录**：
  ```text
  @开发工程师 /cd D:\projects\my-web-app
  ```
切换目录后，Agent 将自动重置当前话题的 CLI 上下文，以新目录作为后续所有文件读取与命令执行的基础。

---

## 6. 安全与权限边界

ThreadPilot 在多人协同群中内置了明确的权限边界，避免越权操作：

- **任务停止鉴权**：只有当前任务的发起人可以点击「停止」按钮安全终止任务，其他成员无法中断。
- **派发鉴权**：只有 Team Leader（CEO 助理）可以在运行时派发任务给团队成员；其他成员调用 `dispatch_task` 会被拒绝，且目标必须来自团队名单、不能派给自己。
- **方案确认鉴权**：产品方案确认卡只有任务发起人可以确认；登录 key 也只有发起人可以提交。
- **编排重试鉴权**：失败子任务一键重试仅允许编排发起人触发，并内置去重与次数上限。
- **QA 隔离保护**：QA 阶段在独立快照环境运行，不污染开发工作树或主分支，并校验审查版本与快照版本一致。
- **数据隔离**：`/metrics`、`/panel` 等查询均按「当前 Bot + 当前群聊 / 会话」范围过滤，避免跨群或跨 Bot 泄露任务元数据。

## 7. 更多能力

- **定时任务**：用 `/schedule` 创建周期任务，到点自动开工（见「定时任务」章节）。
- **任务看板**：用 `/board` 一键初始化飞书多维表格看板，双向同步任务（见「任务看板」章节）。
- **并行编排**：用 `/orchestrate` 拆解大任务并行派发，`/panel` 查看进度（见「并行编排」章节）。
- **可观测性**：用 `/metrics` 查看吞吐、Token、时延与链路记录（见「可观测性大盘」章节）。
- **CLI 登录**：用 `/login` 或 `/<引擎> login` 完成引擎认证（见「CLI 登录」章节）。

完整命令清单与引擎矩阵请参阅「斜杠命令全解析」。
