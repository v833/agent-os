# 5 分钟快速上手

本指南将带你快速熟悉 Agent OS 的基本运作流程，并在飞书中发出你的第一条指令。

---

## 步骤 1：确认环境与服务启动

确保本地已配置好飞书机器人的凭证（`.env` 文件）以及 `config/bots.json` 注册表。

在终端中启动 Agent OS 服务：

```bash
pnpm start
```

当终端出现 `ws client ready` 提示时，表明飞书长连接已成功建立，团队机器人已全部在飞书中就绪。

---

## 步骤 2：进入飞书话题群并查看团队状态

进入已添加 Agent OS 机器人的飞书话题群：

1. 在输入框中输入并发送：
   ```text
   @开发工程师 /team
   ```
2. 机器人将立即回复一张美观的**团队状态卡片**，展示当前在线的团队成员（CEO 助理、产品经理、开发工程师、QA 工程师）以及他们各自绑定的执行引擎与在线状态。

---

## 步骤 3：发起你的第一个任务

在群聊中新建话题或直接 @机器人 提出需求：

```text
@开发工程师 请读取 package.json，告诉我项目名称和主要依赖，不要修改文件
```

---

## 步骤 4：观察实时卡片反馈

发出消息后，飞书会立即弹出一条交互卡片：
1. **执行中（蓝色卡片）**：展示当前执行引擎（Codex / Claude / DimAgent / agy）、正在执行的具体动作（如：查看文件 `package.json`）、累计运行耗时及 Token 消耗。
2. **任务完成（绿色卡片）**：执行成功后，卡片将展示最终解析结果。
3. **随时取消**：如果想要终止，点击卡片上的「停止」按钮即可安全终止任务。

---

## 步骤 5：同一个话题内追问

在刚创建的话题下方继续回复：

```text
那这些依赖里哪些属于开发环境依赖（devDependencies）？
```

Agent OS 会自动保留上一次会话的完整上下文，准确回答你的追问，无需重新重复背景信息。
